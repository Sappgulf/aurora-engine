# Aurora Lumen Foundry Constitution

- The engine never depends on a game.
- Game lore, factions, units, balance, progression, missions, and screens remain game-owned.
- Work on one bounded task per iteration and state measurable acceptance criteria first.
- Simulation behavior must be testable without a renderer, window, audio device, or browser.
- Every engine abstraction requires a second consumer or focused contract test.
- Every user-facing change requires a scripted playtest and screenshot review.
- No new steady-state frame allocation without evidence and a recorded budget decision.
- Native success never hides a browser regression.
- Generated images are production sources until they pass normalization and in-engine review.
- Do not copy StarCraft names, art, dialogue, maps, audio, UI assets, or story.
- Do not weaken tests to make a change pass.
- MCP exposes scenario IDs and fixed validation lanes, never arbitrary commands or paths.
- Do not auto-merge. Push only when the user explicitly asks.
